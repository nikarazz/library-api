# Library API

RESTful API для управления библиотекой. Проект реализует полноценный бэкенд для работы с книгами, авторами, жанрами и комментариями с поддержкой групповых операций (создание, обновление, удаление нескольких объектов за один запрос).

## Архитектура проекта

Проект построен на архитектуре REST (Representational State Transfer). Это означает, что каждому ресурсу (автор, книга, жанр, комментарий) соответствует свой URL, а действия над ресурсом определяются HTTP методом.


Эндпоинты API
Базовый URL: http://127.0.0.1:8000/api/v1/

АВТОРЫ (AUTHORS)

GET /authors/ - получить список всех авторов
GET /authors/?name=текст - получить список авторов с фильтром по имени (поиск по частичному совпадению)
GET /authors/1/ - получить информацию об авторе с ID 1

POST /authors/ - создать одного автора
Тело запроса: {"name": "Имя автора", "birth_date": "1828-09-09", "bio": "Биография"}

POST /authors/ - создать несколько авторов одной командой
Тело запроса: [{"name": "Автор 1"}, {"name": "Автор 2"}]

PUT /authors/1/ - полностью заменить автора с ID 1 (нужны все поля)
PATCH /authors/1/ - частично обновить автора с ID 1 (можно обновить только одно поле)

PUT /authors/?ids=1,2,3 - обновить нескольких авторов
Тело запроса: [{"id": 1, "name": "Новое имя"}, {"id": 2, "name": "Другое имя"}]

PATCH /authors/?ids=1,2,3 - частично обновить нескольких авторов
Тело запроса: [{"id": 1, "bio": "Новая биография"}, {"id": 2, "bio": "Другая биография"}]

DELETE /authors/1/ - удалить автора с ID 1
DELETE /authors/?ids=1,2,3 - удалить авторов с ID 1, 2 и 3

ЖАНРЫ (GENRES)

GET /genres/ - получить список всех жанров
GET /genres/?name=текст - получить список жанров с фильтром по названию
GET /genres/1/ - получить информацию о жанре с ID 1

POST /genres/ - создать один жанр
Тело запроса: {"name": "Название жанра"}

POST /genres/ - создать несколько жанров
Тело запроса: [{"name": "Жанр 1"}, {"name": "Жанр 2"}]

PUT /genres/1/ - полностью заменить жанр с ID 1
PATCH /genres/1/ - частично обновить жанр с ID 1
PUT /genres/?ids=1,2 - обновить несколько жанров
PATCH /genres/?ids=1,2 - частично обновить несколько жанров
DELETE /genres/1/ - удалить жанр с ID 1
DELETE /genres/?ids=1,2,3 - удалить жанры с ID 1, 2 и 3

КНИГИ (BOOKS)

GET /books/ - получить список всех книг
GET /books/?author_id=1 - получить список книг конкретного автора
GET /books/?genre_id=2 - получить список книг конкретного жанра
GET /books/?title=война - найти книги по названию (частичное совпадение)
GET /books/?author_id=1&genre_id=2&title=мир - комбинированная фильтрация
GET /books/1/ - получить полную информацию о книге с ID 1 (включая комментарии)

POST /books/ - создать одну книгу
Тело запроса: {"title": "Война и мир", "author_id": 1, "genre_ids": [1, 2]}

POST /books/ - создать несколько книг
Тело запроса: [{"title": "Книга 1", "author_id": 1}, {"title": "Книга 2", "author_id": 2}]

PUT /books/1/ - полностью заменить книгу с ID 1
PATCH /books/1/ - частично обновить книгу с ID 1

PUT /books/?ids=1,2,3 - обновить несколько книг
Тело запроса: [{"id": 1, "title": "Новое название"}, {"id": 2, "title": "Другое название"}]

PATCH /books/?ids=1,2,3 - частично обновить несколько книг
Тело запроса: [{"id": 1, "description": "Новое описание"}, {"id": 2, "description": "Другое описание"}]

DELETE /books/1/ - удалить книгу с ID 1
DELETE /books/?ids=1,2,3 - удалить книги с ID 1, 2 и 3

КОММЕНТАРИИ (COMMENTS)

GET /comments/ - получить список всех комментариев
GET /comments/?book_id=1 - получить все комментарии к книге с ID 1
GET /comments/1/ - получить комментарий с ID 1

POST /comments/ - создать один комментарий
Тело запроса: {"book_id": 1, "text": "Текст комментария"}

POST /comments/ - создать несколько комментариев
Тело запроса: [{"book_id": 1, "text": "Коммент 1"}, {"book_id": 1, "text": "Коммент 2"}]

PUT /comments/1/ - полностью заменить комментарий с ID 1
PATCH /comments/1/ - частично обновить комментарий с ID 1

PUT /comments/?ids=1,2 - обновить несколько комментариев
PATCH /comments/?ids=1,2 - частично обновить несколько комментариев
DELETE /comments/1/ - удалить комментарий с ID 1
DELETE /comments/?ids=1,2,3 - удалить комментарии с ID 1, 2 и 3

ДОКУМЕНТАЦИЯ

GET /api/docs/ - открыть Swagger UI (интерактивная документация)
GET /api/schema/ - получить OpenAPI схему в формате JSON

АДМИН-ПАНЕЛЬ

GET /admin/ - вход в административную панель Django

ПРИМЕРЫ ЗАПРОСОВ ДЛЯ КОПИРОВАНИЯ

Создать автора:
curl -X POST http://127.0.0.1:8000/api/v1/authors/ -H "Content-Type: application/json" -d "{"name": "Лев Толстой", "birth_date": "1828-09-09"}"

Создать жанр:
curl -X POST http://127.0.0.1:8000/api/v1/genres/ -H "Content-Type: application/json" -d "{"name": "Роман"}"

Создать книгу:
curl -X POST http://127.0.0.1:8000/api/v1/books/ -H "Content-Type: application/json" -d "{"title": "Война и мир", "author_id": 1, "genre_ids": [1]}"

Создать комментарий:
curl -X POST http://127.0.0.1:8000/api/v1/comments/ -H "Content-Type: application/json" -d "{"book_id": 1, "text": "Отличная книга"}"

Получить все книги автора:
curl http://127.0.0.1:8000/api/v1/books/?author_id=1

Получить книгу с комментариями:
curl http://127.0.0.1:8000/api/v1/books/1/

Обновить книгу:
curl -X PATCH http://127.0.0.1:8000/api/v1/books/1/ -H "Content-Type: application/json" -d "{"description": "Новое описание"}"

Удалить несколько книг:
curl -X DELETE "http://127.0.0.1:8000/api/v1/books/?ids=1,2,3"

Удалить несколько авторов:
curl -X DELETE "http://127.0.0.1:8000/api/v1/authors/?ids=1,2,3"
